# 🤖 Agentic AI Projects

A collection of small **Agentic AI projects and experiments** built using Python and the **Agno framework**.

This repository explores different concepts in Agentic AI, including AI agents, tool usage, memory, multi-agent teams, financial analysis, and YouTube video analysis.

---

## 📂 Projects

### 🎥 YouTube Video Analyzer

An AI-powered application that analyzes YouTube videos and generates a structured analysis report.

The application uses **Agno**, **Groq**, and **YouTube tools**, with a **Streamlit** interface for user interaction.

**Features:**
- Accepts a YouTube video URL
- Analyzes video content
- Identifies video structure and important timestamps
- Generates a structured analysis report
- Interactive Streamlit interface

**Run the application:**

```bash
streamlit run youtube-analyzer/ui.py
